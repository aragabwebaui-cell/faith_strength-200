FAITH & STRENGTH 200 — PHONE SETUP

Files in this folder:
- index.html
- manifest.json
- icon-192.png
- icon-512.png
- service-worker.js

IMPORTANT:
Opening index.html directly from Samsung My Files may still show a generic HTML icon.
For the FS200 custom icon to work properly, upload this folder to a website/HTTPS host
(such as Netlify), open the website in Chrome, then choose:
Chrome menu > Add to Home screen / Install app.

The app can then use the FS200 icon and open like a standalone app.
